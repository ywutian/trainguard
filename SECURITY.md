# Security reporting

Report a suspected vulnerability through the repository's [private vulnerability reporting form](https://github.com/ywutian/trainguard/security/advisories/new). Private reporting is enabled for this repository. Do not post exploit details, credentials, customer data, model weights, or checkpoint contents in a public issue.

Include the affected version or commit, a minimal reproduction, the expected and observed behavior, and the potential impact. Use synthetic data whenever possible. The maintainers will acknowledge and triage the report through the private advisory. The response time and patch schedule depend on the reported issue and available maintainers; no around-the-clock service commitment is implied by this policy.

The current repository contains experimental recovery software and evaluation candidates. It has no production-supported release. Customer-specific security contacts and response targets must be stated in the signed order and support plan. Coordinated public disclosure should wait until the maintainers and affected customers have had a reasonable opportunity to assess and address the issue.
