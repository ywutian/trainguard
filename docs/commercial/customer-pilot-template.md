## 2. 签署前的资格与基线

目标买方假设是管理高成本、跨节点 PyTorch 长训练的 ML 平台团队。销售访谈收集过去 90–180 天作业故障、重跑、人工处置和实际 GPU/存储账单，确认可隔离演练且能提供状态清单。短时单卡作业、无法冻结训练状态或不能授权故障演练的团队不进入首批试点。这些是筛选假设，未有客户访谈或购买证据前不写成已验证市场需求。

双方在启动前冻结 `RunSpec`：代码/镜像摘要、PyTorch/CUDA/驱动版本、rank/节点和设备映射、数据版本及来源、优化器/调度器/RNG/AMP/样本游标和用户状态清单、检查点目录与对象前缀、容量/保留、恢复次数和超时、外部副作用、故障演练权限。未声明或未验证的状态标 `UNVERIFIED`；环境变化须重新预检和修订范围。

当前软件有固定模型和受信任单文件 CPU DDP 作业的本机评估入口，仍只有本地检查点恢复路径。该入口的摘要不覆盖导入模块、外部数据和副作用，也未经过真实客户作业验收。客户状态适配 SDK、真实对象服务、跨主机隔离和实卡矩阵尚未放行；因此不能将本模板当作已经可执行的客户生产服务订单。可以先签**有限付费接入研究**，使用通过本机门槛的 `EVALUATION_ONLY` 包做隔离环境评估，并在工作说明书中逐项列出未实现能力、可交付研究结果、风险和退出条件。只有在客户环境完成冻结矩阵验收后，才可签该工作负载与环境的受限技术保护范围；广泛商用还需完整发布门槛和真实付费签收。采购/安全审查可先查候选包，但不得把评估包用于未经批准的生产自动接管。

## 3. 故障演练授权与验收附件

## 4. 责任、支持与安全

| 事项 | 客户 | 供应商 |
| --- | --- | --- |
| GPU、集群、调度器、网络、对象账单与备份 | 提供、授权、运营 | 写明依赖和诊断所需权限 |
| 训练数据、状态清单、外部副作用 | 声明、合法使用、审查 | 验证已登记范围并报告未验证状态 |
| 软件交付、缺陷修复与证据 | 按权限安装并参与验收 | 提供固定版本、哈希、运行手册、复测结果 |
| 故障演练 | 授权窗口、值守、停止与回滚放行 | 按授权矩阵执行并保留原始结果 |
| 事故处置 | 管理基础设施并提供事件信息 | 在约定时段受理、定位并安全停止或升级 |

Sev1 为疑似错误状态、双写、无法可靠恢复或数据安全事件，先暂停接管/发布并保存证据；Sev2 为保护降级但训练仍可继续；Sev3 为非紧急缺陷和文档。订单页必须填写实际有人值守的时区、时段、渠道、首次响应目标、更新频率及升级联系人。首次响应不等于修复时限；未建立值班和实测 SLO 前不承诺全天候支持或通用可用率。预先演练坏候选、容量不足、旧 actor、接管阻断、控制器故障和证据损坏的处置。

原始运行目录可能含样本标识、训练路径、模型和检查点；仅留在客户受限环境。`support-bundle` 只导出白名单摘要；向供应商传输前仍须客户审核和书面批准。临时访问列明授权人、有效期、最小权限、审计、撤销及到期删除证明。盘点日志、权重、样本、密钥和报告的实际出站流量；供应商不得把客户数据用于模型或营销改进，除非另有明确授权。采购包应附交付包哈希、候选 wheel 对应的 SBOM、第三方许可证声明清单、经核验的脱敏漏洞扫描结果与扫描时间、原始报告的 SHA-256 及授权审查方受控查阅原件的方式、[私密漏洞上报入口](../../SECURITY.md)、版本兼容/补丁路径、权限矩阵和已知例外。许可证清单需由法务逐项审查适用义务；扫描为当时已知结果，不能替代持续通报和补丁处置。不能声称取得未经审计的安全认证或供应链等级。

个人数据、医疗信息、消费者隐私、跨境与欧盟产品安全义务按**销售地区、客户数据和供应商实际访问**筛查，不能一刀切。若供应商会处理受 GDPR 保护的客户个人数据，核对控制者/处理者和第 28 条协议；若远程排障会接触受 HIPAA 保护的 PHI，访问前审查业务伙伴协议；若向欧盟市场提供软件，审查适用产品安全规则。责任限制、赔偿、税务、出口和适用法律交由专业人员按交易审核。

## 5. 报价、计量与续约

首单采用固定范围试点费，按预计集成、演练、报告、缺陷复测及约定支持人天核算成本底线；客户 GPU/存储账单单列。费用与验收工作量绑定，不与“训练一定通过”绑定。年度阶段若存在可销售的增值交付，应按**已验收工作负载族 × 环境**及支持/适配范围报价；现有 MIT 代码不可被描述为需购买排他使用权。尚无客户价格或付费意愿证据，不填写虚构标价。

ROI 以客户原有方案为对照：先逐次归集原有失败事件中互不重叠的有效重跑 GPU 小时和人工处置小时；在同一故障、镜像与资源条件下测增量改善，再减去新增检查点计算/IO、对象存储、演练、运维及服务费。用客户实际费率，不借用竞争产品公开标价。无自然故障的观察期只报告净开销和演练的条件改善，不报告已经节约的费用。历史故障率乘以条件改善仅列为情景预测，附原始账本、样本量与不确定性。按受保护时长收费前须建立可重放、去重、对账和争议更正的权威计量；当前实验统计不得用于开票。

用 [`pilot-ledger-template.json`](pilot-ledger-template.json) 填写同故障配对数据，执行 `python scripts/calculate_pilot_value.py <ledger.json> --output <result.json>`。脚本拒绝重复场景和负成本，逐项扣除新增计算、人工、存储、演练和服务费，输出仅是**这组演练的成本差额**；重复演练次数会改变总额，不可年化、作为定价上限、实际节省宣称或开票依据。年度价值须另以客户真实事故频率、账本、观察期间和可归因改善作保守测算，原始记录与双方核对另行保留。

季度价值复核记录：实际支持矩阵覆盖、版本变更后的复测、阴性对照拒绝、真实事故的恢复正确性和 RPO/RTO、额外开销、发现并修复的缺陷、支持工时和客户继续使用意愿。续约以这些实测结果与双方商业谈判为准。

## 6. 宣称边界和放行

截至本草案日期仅能描述已复核的本机 CPU 结果。禁止宣称业界首创逐步等价、零数据丢失、所有故障均可恢复、物理环境 1:1 模拟、已实现固定节省比例、任意框架/拓扑支持、CPU 结果代表实卡生产通过、已有付费客户或未经测量的 SLA。客户案例和报价只在真实记录及授权后发布。

发布必须使用 [`release-gates.json`](release-gates.json) 的同一候选版本与证据。任何 `FAIL`、`BLOCKED`、证据哈希失配或源码/交付包变化都阻断生产声明；没有真实客户签收也不得描述为已经商业验证。客户环境资源到位后按此模板冻结矩阵并执行，同一失败修复后重测直至全部适用门槛通过。
